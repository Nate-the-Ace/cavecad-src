Trace one wall across several passes so it stays one line

A passage wall is longer than one comfortable drag. Six drags should leave one line, not six.

Steps

  1. Arm the feature once.
  2. Drag along the wall as far as is comfortable and release.
  3. Start the next drag where the last one stopped. It grows the same line: same entity, same tags, one end to warp, one row in a revision. One undo takes the extension back.
  4. To continue a wall traced on an earlier day, hold Shift as you press. That joins any line end within a foot on that layer.

The corner rule

A plain drag continues only your own last stroke, on that exact layer. At a corner where two walls meet, a rule that joined any nearby end would fuse them into one fitted curve and round the corner off. So starting a new wall at a corner is safe — and Shift there is the mistake.

Try it on Truitt

Trace a long wall in three passes, then select it: one line. Then start a stroke deliberately at a corner where two walls meet: it must not join.

When it refuses

  • Delete Last refuses after a pass that grew an earlier line, and sends you to Ctrl+Z. It is refusing to delete more than you drew.
