New Cave Map

Start a sheet from the NSS template, already carrying the control layers and the symbol blocks. ncm

When you reach for it

Only for a cave nobody has drawn yet. A cave that came in through Import Cave... already has a drawing on this template — making a second one leaves you with two.

Steps

  1. Cave Survey > New Cave Map.
  2. Save it into the cave's own folder. The folder, not the file, is the project: scans are stored relative to it.
  3. Type the first trip in Survey Notebook.
