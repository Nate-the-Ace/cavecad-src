Feature Trace

Trace walls and other features freehand: hold the button and drag along the sketch, and a smooth line follows. featuretrace


Search by any of a feature's names: "gour" finds the rimstone dam, "shaft" the pit.

When you reach for it

For every line on the map that is not survey. Walls, ceiling, floor, breakdown outlines — all of it.

Steps

  1. Pick the feature from the panel. One tile per feature, not one per view.
  2. Drag along the scan. The line follows at one control point per foot of cave.
  3. Where you drag decides the view. A stroke in the plan lands on the plan layer; one inside a profile band's box lands on that band's run layer; one inside an open section bay lands on the section layer, carrying the station the bay was opened at. The readout above the tiles names the layer under the cursor before you press.
  4. Carry on where you stopped and the stroke grows that line instead of making a second one — trace a long wall in six passes and it is one line, with one end to warp and one row in a revision. One undo takes the extension back.
  5. Hold Shift as you press to continue any line end within a foot on that layer, including one traced weeks ago.

Finding a feature

The search box filters tiles by name and by the other words for the same thing — "gour" finds the rimstone dam, "shaft" finds the pit, "boulders" finds breakdown. Press Return with one tile left showing and that feature is armed and drawing. Escape puts the tool down. The Recent strip holds the last five features you armed, as pictures; it survives a restart.

Each tile carries a count of that feature in the view you are in, so a passage whose walls are traced and whose floor is not says so where you are already looking.

Try it on Truitt

Trace one long wall in three passes without lifting anything but the mouse. Select it afterwards: it must be one line, not three.

When it refuses

  • A plain drag continues only your own last stroke on that exact layer. At a corner where two walls meet it must not join — fusing them would round the corner off. Use Shift only when you mean it.
  • Delete Last refuses after a stroke that grew an earlier line. Use Ctrl+Z.
