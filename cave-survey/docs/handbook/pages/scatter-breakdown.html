Scatter Breakdown

Fill closed BREAKDOWN-BOUNDARY polylines with breakdown symbols, per boundary. scb

When you reach for it

For breakdown drawn the old way, as a boundary polyline. New work is easier through Area Fill, which draws the boundary and the fill in one gesture.

Steps

  1. Draw or select the closed boundary.
  2. Run the tool. Re-running clears and refills only the boundaries it processes, in one undo step.

Each boundary's seed is rolled once and kept, so its pile looks the same across re-runs, an edit or a reload.

When it refuses

  • An open boundary is skipped. Check Map flags that one.
