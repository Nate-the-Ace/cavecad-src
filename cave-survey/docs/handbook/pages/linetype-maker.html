Linetype Maker

Make, edit and import your own linetypes. ltm


New linetype: name it, add a text row, set a dash length; the preview follows.

When you reach for it

When a line on your map needs to say what it is along its whole length: a stream that repeats W, a boundary that repeats LIMIT, or a dash pattern the template does not have.

How it works

  1. Pick a linetype from the list, or press New.
  2. Give it a name: letters, digits, _ - $, no spaces. Pick or type a Category — the Draw panel's Custom Linetypes section groups your linetypes by it.
  3. Edit the rows. A positive Length draws a dash, a negative one leaves a gap, 0 is a dot. Type in Text and it is drawn in that row. Font is a list drawn in each font, exactly as it prints; Size is its height; Rot° turns it. Lengths and sizes are in the drawing's own units: on a map in feet, a Length of 2 is a two-foot dash and a Size of 1 is text a foot tall. A pattern much smaller than the lines it is used on draws solid, so size it to the map.
  4. A text row is a gap sized to its text. Make the text bigger, longer or another font and the gap grows by the same amount, so the text never runs into the dashes; type a longer Length for more room around it.
  5. Anchor places the text: Left, Center or Right in its own row, and Top, Middle or Bottom against the line. New text starts at Middle center. A linetype imported with its own placement shows Custom until you pick an anchor.
  6. + Dash, + Gap and + Text add the new row just below the selected rows, or at the bottom when nothing is selected.
  7. To change several rows at once, Shift- or Cmd-click their row numbers, then change a value in any one of them. Remove, ↑ and ↓ act on every selected row.
  8. Watch the preview. Anything wrong is listed under it.
  9. Save to Library to keep it; Apply to Drawing to use it in the open drawing; Test to start the Line tool with it straight away. Press Escape when done and your previous linetype comes back.

Bringing your own

Import… reads an AutoCAD .lin file, or the linetypes inside another drawing. Tick the ones you want; a name you already have says so, and ticking it replaces yours.

Good to know

Your library is one file beside your caves, Documents/Cave/linetypes/CaveCustomLinetypes.lin. It syncs with them and no CaveCAD update ever replaces it. Every new cave map gets the whole library.

Text inside a linetype cannot contain spaces or commas.

Text linetypes are saved as real DXF linetypes, so other CAD programs draw them too.

Symbols drawn into a line (ticks, chevrons) are coming next; until then use Shaped Lines.
