Attach Drawing

Brings another drawing into this one as a linked external reference: its visuals as a single unit that stays connected to its file. attachdrawing (also xref)

When you reach for it

A regional map built from several caves, a cave drawn over a surface map, or a profile shown with its plan - without copying anything. When the other drawing changes, this one offers to update.

Two choices

How it is attached. Overlay shows the other drawing's own geometry only: whatever it has itself referred to does not come along. Attach shows it and whatever it refers to. Two drawings that attach each other are refused (they would go round in a circle).

How the path is kept. Absolute keeps the full path to the file. Relative keeps it relative to this drawing's folder, so a cave folder can be moved or shared. Save the drawing first to use relative.

What you pick becomes the choice offered next time. To begin with it is Overlay and Absolute.

What you see

The other drawing's layers appear as Name|LAYER, so they never mix with yours. It acts as one object: select it, move it, copy it.

Where it is

The Cave Survey menu. List and manage them with External References.
