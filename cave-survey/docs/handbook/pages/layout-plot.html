Plot Layout

Plots this layout, or all of them into one PDF, in the cave's PDF folder (or where you pick for a drawing with no folder yet). Before it plots it looks for viewports that would print images -- an aerial photograph shows where the cave is, a scan is somebody's field book -- and offers to leave them out. plotlayout

When you reach for it

Whenever a sheet is ready to hand to someone.

Where it is

The Layout menu and the Cave Survey menu. It works on a layout only.
