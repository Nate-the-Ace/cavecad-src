Sketch Scans

Browse the cave's scanned sketches, and put one under the drawing at the right size and angle. ss


The cave's scans as a tree, a preview beside it, and the tabs for Plan, Profile and Cross Section.


Pick scans in the tree and the preview follows; the tabs hold each view's buttons.

When you reach for it

Before any tracing. A scan that is not lined up with the survey is worse than no scan: every wall you trace off it is wrong by the same amount.

Steps

  1. Pick the tab for the job — Plan, Profile or Cross Section. Each holds only the buttons that view uses, in the order they are used.
  2. Align on Scan picks the stations on the scan itself in the zoomable viewer — wheel to zoom, middle-drag to pan, left-click a station and name it from the drawing's own list — then places the scan already fitted. No insert-then-hunt-then-align.
  3. Add a Scan and Fit by Hand... file-picks any page — one whose station marks cannot be read, a photo still on a phone, a page scanned to the Desktop — drops it over the survey at a guessed size and fits it there: click a point on the image, click where it belongs. Two points for a plain fit; three or more also take out the scanner’s own stretch and skew, with a report of how far the worst point missed by. The dialog opens in this cave’s scans folder, and a page picked from there keeps its trim. Double-clicking a row in the list does the same thing.
  4. Right-click a scan for Mark Complete. A tick appears beside it, and on a trip folder when every page in it is done.

You can also drag image files straight onto the preview. They are copied into the cave's scans folder — into whichever trip folder is selected — never moved, and never over the top of a file already there.

Try it on Truitt

Put a scan under the drawing twice without touching the menu bar: once with Align on Scan, once with Add a Scan and Fit by Hand....

Getting out of an assignment

While you are assigning stations, the view tabs are locked — a scan must not end up fitted to half a plan and half an elevation — and the assign button changes to Place as soon as the first station is picked. Cancel Assignment, beside it, abandons the whole thing: the picks are dropped, the tabs unlock, and nothing is placed. Nothing was drawn, so there is nothing to undo.

Selecting a different scan abandons it the same way — those picks were points on the page you were looking at.

A page that arrived the wrong way round

Two buttons sit with the zoom controls. ↻ turns the page a quarter turn clockwise; ⇄ mirrors it left-for-right, for a sheet photographed through its back or traced on the reverse of tracing paper. For a top-to-bottom flip, mirror it and then turn it twice.

Both rewrite the file on disk, deliberately: the preview, the trim box, the two-point fit and the section bay all read the pixels off disk, so a correction carried alongside the file would have to be honoured by each of them separately. Trimmed crops of that page go with the old pixels, and any placement of it already in the drawing keeps its frame while the sketch inside it moves — re-align those.

Both panels stay on the same page

Sketch Scans and the Survey Notebook browse the same folder, and they now follow each other: select a page in one and the other moves to it. While tracing that is the point — one pane holds the page being read, the other the page being placed, and they are the same page.

The page you are on is remembered in the drawing, so it comes back when you reopen the cave, on any machine and for anyone else you hand the file to. That means moving to another page marks the drawing as changed; close without saving and it keeps the page the file already named.

Clearing out the crops

Every time you trim a page, the cut-out is written as its own file under scans/Trimmed/. Move the box a little and trim again and that is another file. They never show up in the list — they are not field notes — so over a season they pile up unseen, fat PNGs by the hundred.

Right-click anywhere in the scan tree and take Delete N Trimmed Crops, which tells you how much space they are using before you agree. Crops the open drawing is currently showing are left alone; the rest go.

Nothing is lost by this. A crop is a derivative: the drawing remembers which page it came from and which box was cut, so Repair Drawing cuts any of them again when it is needed. The same entry is on the Survey Notebook's copy of the tree.

When it refuses

  • A scan whose file has moved is reported rather than silently blank — put it back with the relink path.
