Attach another drawing to this one, and manage the drawings already attached. One window for both. externalreferences (also xrefs, attachdrawing, xref)

When you reach for it

A regional map built from several caves, a cave drawn over a surface map, or a profile shown with its plan - without copying anything. The other drawing appears as one linked object, and when its file changes this drawing offers to update.

Attaching a drawing

Press Attach drawing..., pick the file, and choose two things. It is placed by its entrance location: when both drawings have an entrance location set, the attached drawing lands on the same ground as this one, whatever each file's own 0,0 is. If either has no location it goes at this drawing's 0,0 and the message says why; untick Place it by its entrance location to force 0,0. Nothing in either drawing's own coordinates changes.

How it is attached. Overlay shows the other drawing's own geometry only: whatever it has itself referred to does not come along. Attach shows it and whatever it refers to. Two drawings that attach each other are refused (they would go round in a circle).

How the path is kept. Absolute keeps the full path to the file. Relative keeps it relative to this drawing's folder, so a cave folder can be moved or shared. Save the drawing first to use relative.

What you pick becomes the choice offered next time. To begin with it is Overlay and Absolute. The other drawing's layers appear as Name|LAYER, so they never mix with yours.

The list

  • up to date - the file is as it was when read.
  • CHANGED - the file is newer. Press Update. (An open drawing also offers this by itself.)
  • MISSING - the file is gone. The last picture is kept; nothing is deleted.

The buttons

  • Attach drawing... brings in another drawing.
  • Update reads the file again.
  • Overlay <-> Attach switches the attachment style and reads the file again.
  • Absolute <-> Relative changes how the path is kept.
  • Bind makes it an ordinary block: the link is dropped, the picture stays.

Where it is

The Cave Survey menu and the Cave Survey tab (External references).
