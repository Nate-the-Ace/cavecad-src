Package Cave Project

Assemble a cave project into one zip in ~/Documents/Cave/depot. pc


Sanitized by default; Full archive says so in the file name. Cancelled here, nothing is written.

When you reach for it

Handing a cave to another cartographer, filing it with a survey, or keeping your own archive copy.

What goes in

The drawing, the maps already in PDF/, the survey in every interchange format (Compass, Walls, Survex, Therion, CSV), and a manifest anyone can read without CaveCAD.

Sanitized or full

Sanitized by default: the copied drawing loses its geographic anchor, and no aerial photograph travels with it. A full archive keeps both, says so in its file name, and is meant for your own storage or for handing a project to the next cartographer.

The first rule of this suite is that a cave's entrance location does not travel by accident. Sanitized is the default for that reason, not as a convenience.

When it refuses

  • It never plots a PDF, and never touches the original drawing.
