Rebuild the extended elevation

The side view beside the plan: one band per survey run, floor and ceiling from LRUD and splays.

Normally you do nothing

It is rebuilt with every Draw from the Notebook's own survey model. Reach for the menu entry only when the drawing has been edited elsewhere, or when a band looks wrong and you want it rebuilt from the drawing's own tags.

Steps

  1. Cave Survey > Generate Profile.
  2. Read the report: a run it could not band is named rather than skipped in silence.

Drawing in it

The bands are real places. A stroke inside a band's bounding box lands on that band's run layers — walls, shaped lines and symbols all follow the same rule, so there is no view button to get wrong.
