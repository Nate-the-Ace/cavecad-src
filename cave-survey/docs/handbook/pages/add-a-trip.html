Add a trip to a cave you already have

A cave is one drawing holding numbered trips. A second day underground is a trip, not a second file.

Steps

  1. Cave Survey > Caves, pick the cave, and read the trip table: each trip's date, team, shots and the stations it stopped at.
  2. Start a trip tied into an open end from there, or open the drawing and use Survey Notebook directly.
  3. Type the new trip's shots, starting from the station the last trip stopped at.
  4. Set the date and team. Declination is estimated from that date and the cave's location.
  5. Draw. Only the new trip is drawn — the rest of the cave is left alone, which is what makes it quick.

When it refuses

  • A shot from a station the drawing does not have is refused. Check the station name against the trip that reached it.
  • If the whole cave redraws, something moved existing stations — a corrected declination or a re-closed loop. That is correct, not a fault.
