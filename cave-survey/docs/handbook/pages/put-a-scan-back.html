Put a scan back when its file moved

A drawing stores a scan as a reference to a file on disk. Move, rename or re-sync the folder and the image goes blank while the drawing still knows where it was placed.

Steps

  1. Cave Survey > Repair Drawing.
  2. Press OK. The scan pass always runs — there is no checkbox for it — so the other three can be unticked if you only want this one.
  3. Read the report line: it says how many references it put back, and names any it could not.

The placement is not re-done. The scan returns at the size, angle and position it was fitted at, so nothing traced off it has to move.

When it refuses

  • A file that is genuinely gone cannot be relinked. Put the page back in the cave's scans/ folder — under any trip folder — and run it again.
  • A page you replaced with a differently sized rescan comes back at the old fit. Re-align it.
