# Area Fill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Area Fill 0.9.116.0 — thirteen UIS/Therion area patterns drawn by a freehand closed stroke, filled by hatch or seeded scatter, regenerated when the boundary moves, extensible by a custom-pattern editor — and turn the Draw panel into a reorderable two-wide grid so a third section fits.

**Architecture:** An area is a boundary spline (the truth) plus a derived fill (disposable), the Shaped Lines model. `Core/CsArea.js` owns the catalog, a seeded Park–Miller RNG, fill generation and regeneration, with no widgets. `AreaFill/` owns the panel section, the stroke action, the editor tab and the transaction listener. Custom patterns are `AREA_*` blocks in the caver's own symbol library, self-describing through marker XDATA, saved and imported by the existing `CsSymbolStore`.

**Tech Stack:** QCAD/CaveCAD ECMAScript add-on (QtScript, ES5 only — no `let`, no arrow functions, no `Math.imul`), QCAD JS bridge widgets (QDockWidget, QGridLayout, QMenu), `RHatchData`/`RHatchEntity`, `RBlockReferenceEntity`, `RTransactionListenerAdapter`, XDATA through `CsTags`. Tests: `tests/run_all.sh` (python structural tests + headless CaveCAD suites).

**Spec:** `docs/superpowers/specs/2026-09-11-area-fill-design.md`

**User decisions (already made):**
- "Both, per pattern" — hatch entities for water/sump/flowstone/moonmilk, scattered geometry for the chunky patterns.
- "Freehand drag, auto-closed" — the boundary is one press-drag-release, no click-by-click mode, no fill-an-existing-region mode.
- "One element + a placement rule" — the custom editor saves a block plus scatter/tile rule, never a `.pat`.
- "Redraws itself, live" — a transaction listener regenerates on boundary edit.
- "Third column in Draw panel" — Areas is a section of Draw, not its own dock.
- "Becomes the Blocks area button" — ScatterBreakdown keeps its menu entry, loses its private engine.
- "The above is the exact layout I want" — two-wide grid, lone last section spans full width, tile columns derived from cell width (2 half / 4 full), a folded section keeps its cell, new sections append.
- "Let me right click to move sections up or down" — header context menu, which `CsPanel.stackAdd` already provides.

Header comment in the suite's voice, then:

```js
var CsArea = {};

/** Elements per 100 square drawing units, before the panel's own
 *  density multiplier. */
CsArea.BASE_DENSITY = 16;

/**
 * A repeatable random source.
 *
 * Park-Miller minimal standard, NOT an LCG with a big multiplier and
 * NOT Math.imul: this bridge is ES5, Math.imul is absent, and a
 * multiplier over ~2^24 loses bits in a double long before it wraps.
 * 16807 * 2^31 stays under 2^53, so every step is exact.
 *
 * Math.random cannot be seeded, and an unseeded scatter reshuffles a
 * whole boulder room every time the listener fires.
 */
CsArea.rng = function(seed) {
    var state = Math.floor(Math.abs(isNull(seed) ? 1 : seed)) % 2147483647;
    if (state === 0) {
        state = 1;
    }
    return function() {
        state = (state * 16807) % 2147483647;
        return (state - 1) / 2147483646;
    };
};

/** A seed for a new area. Math.random is fine HERE -- it is rolled
 *  once, written to the boundary, and never rolled again. */
CsArea.newSeed = function() {
    return 1 + Math.floor(Math.random() * 2147483645);
};
```

- [ ] **Step 3: Implement in `CsArea.js`**

```js
/** Even-odd point in polygon. A self-intersecting boundary is answered
 *  by this rule and not repaired -- a figure-eight fills its lobes. */
CsArea.pointInPolygon = function(px, py, verts) {
    var inside = false;
    var n = verts.length;
    if (n < 3) {
        return false;
    }
    var x1 = verts[0].x, y1 = verts[0].y;
    for (var i = 1; i <= n; i++) {
        var x2 = verts[i % n].x, y2 = verts[i % n].y;
        if ((y1 > py) !== (y2 > py)) {
            var xInt = (x2 - x1) * (py - y1) / (y2 - y1) + x1;
            if (px < xInt) {
                inside = !inside;
            }
        }
        x1 = x2;
        y1 = y2;
    }
    return inside;
};

/** Unsigned area of a polygon. */
CsArea.polygonArea = function(verts) {
    var a = 0;
    for (var i = 0; i < verts.length; i++) {
        var p1 = verts[i], p2 = verts[(i + 1) % verts.length];
        a += p1.x * p2.y - p2.x * p1.y;
    }
    return Math.abs(a) / 2;
};

/** The bounding box of a polygon: {minX, minY, maxX, maxY}. */
CsArea.bounds = function(verts) {
    var b = { minX: verts[0].x, minY: verts[0].y,
              maxX: verts[0].x, maxY: verts[0].y };
    for (var i = 1; i < verts.length; i++) {
        b.minX = Math.min(b.minX, verts[i].x);
        b.minY = Math.min(b.minY, verts[i].y);
        b.maxX = Math.max(b.maxX, verts[i].x);
        b.maxY = Math.max(b.maxY, verts[i].y);
    }
    return b;
};

/**
 * Where a scattered pattern's elements go.
 *
 * Rejection sampling inside the bounding box, with a cap so a boundary
 * that is nearly all box -- a long thin passage cutting a diagonal --
 * cannot spin. The cap is generous: a 10% hit rate still fills.
 *
 * \return [{x, y, block, scale, angle}, ...]
 */
CsArea.placements = function(verts, entry, seed, scale, density) {
    var out = [];
    if (verts.length < 3 || entry.engine !== "scatter") {
        return out;
    }
    var area = CsArea.polygonArea(verts);
    var want = Math.round((area / 100) * entry.density *
        (isNull(density) ? 1.0 : density));
    if (want <= 0) {
        return out;
    }
    var b = CsArea.bounds(verts);
    var w = b.maxX - b.minX, h = b.maxY - b.minY;
    var rand = CsArea.rng(seed);
    var tries = 0, cap = want * 60 + 500;
    var mul = isNull(scale) ? 1.0 : scale;
    while (out.length < want && tries < cap) {
        tries++;
        var x = b.minX + rand() * w;
        var y = b.minY + rand() * h;
        var pickBlock = rand();
        var pickScale = rand();
        var pickAngle = rand();
        if (!CsArea.pointInPolygon(x, y, verts)) {
            continue;
        }
        var blockIndex = Math.min(entry.blocks.length - 1,
            Math.floor(pickBlock * entry.blocks.length));
        out.push({
            x: x, y: y,
            block: entry.blocks[blockIndex],
            scale: mul * (entry.scaleMin +
                pickScale * (entry.scaleMax - entry.scaleMin)),
            angle: entry.rotate ? pickAngle * 2 * Math.PI : 0.0
        });
    }
    return out;
};
```

Note the four `rand()` calls happen before the inside test on purpose: drawing the same number of values per attempt is what makes the sequence depend only on the seed and the geometry, never on how many points happened to land outside.

```js
/** The XDATA key every generated fill entity carries. */
CsArea.OWNER_KEY = "AreaOwner";

/** Keys on the boundary itself. */
CsArea.ID_KEY = "AreaId";
CsArea.PATTERN_KEY = "AreaPattern";
CsArea.SCALE_KEY = "AreaScale";
CsArea.DENSITY_KEY = "AreaDensity";
CsArea.SEED_KEY = "AreaSeed";

/** How finely a boundary curve is sampled into a polygon. */
CsArea.STEP = 0.25;

/** A boundary entity as [{x, y}, ...]. Splines, polylines and anything
 *  else with a shape all go through getPointCloud, so one path covers
 *  every boundary a caver can draw. */
CsArea.vertsOf = function(entity) {
    var out = [];
    try {
        var shape = entity.getData().castToShape();
        var cloud = shape.getPointCloud(CsArea.STEP);
        for (var i = 0; i < cloud.length; i++) {
            out.push({ x: cloud[i].x, y: cloud[i].y });
        }
    } catch (e) {
        return [];
    }
    return out;
};

/**
 * Builds one area's fill into an operation the caller applies.
 *
 * \param opts {id, seed, scale, density, layer}
 * \return {ok, count, reason}
 */
CsArea.build = function(doc, op, boundary, entry, opts) {
    if (isNull(entry)) {
        return { ok: false, count: 0, reason: "no such pattern" };
    }
    var verts = CsArea.vertsOf(boundary);
    if (verts.length < 3) {
        return { ok: false, count: 0, reason: "the boundary has no area" };
    }
    if (entry.engine === "filled") {
        return CsArea.buildHatch(doc, op, boundary, entry, opts);
    }
    var places = CsArea.placements(verts, entry, opts.seed, opts.scale,
        opts.density);
    var made = 0;
    for (var i = 0; i < places.length; i++) {
        var block = doc.queryBlock(places[i].block);
        if (isNull(block)) {
            return { ok: false, count: made,
                reason: "this drawing has no " + places[i].block + " block" };
        }
        var data = new RBlockReferenceData(block.getId(),
            new RVector(places[i].x, places[i].y),
            new RVector(places[i].scale, places[i].scale),
            places[i].angle, 1, 1, 1, 1);
        var ref = new RBlockReferenceEntity(doc, data);
        ref.setLayerId(doc.getLayerId(opts.layer));
        CsTags.set(ref, CsArea.OWNER_KEY, opts.id);
        op.addObject(ref, false);
        made++;
    }
    return { ok: true, count: made, reason: "" };
};

/** One hatch entity over the boundary loop. BEDROCK has no pattern and
 *  draws nothing: its edge IS the symbol. */
CsArea.buildHatch = function(doc, op, boundary, entry, opts) {
    if (isNull(entry.pattern)) {
        return { ok: true, count: 0, reason: "" };
    }
    var shape = null;
    try {
        shape = boundary.getData().castToShape();
    } catch (eShape) {
        return { ok: false, count: 0, reason: "this boundary has no shape" };
    }
    var data = new RHatchData(entry.solid === true,
        isNull(entry.patternScale) ? 1.0 : entry.patternScale,
        isNull(entry.patternAngle) ? 0.0 : entry.patternAngle,
        entry.pattern);
    data.newLoop();
    data.addBoundary(shape.clone());
    var hatch = new RHatchEntity(doc, data);
    hatch.setLayerId(doc.getLayerId(opts.layer));
    CsTags.set(hatch, CsArea.OWNER_KEY, opts.id);
    op.addObject(hatch, false);
    return { ok: true, count: 1, reason: "" };
};

/** Every entity id belonging to one area's fill. */
CsArea.ownedBy = function(doc, areaId) {
    var out = [];
    var ids = doc.queryAllEntities(false, true);
    for (var i = 0; i < ids.length; i++) {
        var e = doc.queryEntity(ids[i]);
        if (isNull(e)) {
            continue;
        }
        if (CsTags.get(e, CsArea.OWNER_KEY) === areaId) {
            out.push(ids[i]);
        }
    }
    return out;
};

CsArea.countOwned = function(doc, areaId) {
    return CsArea.ownedBy(doc, areaId).length;
};

/** Deletes one area's fill into an operation the caller applies. */
CsArea.clear = function(doc, op, areaId) {
    var ids = CsArea.ownedBy(doc, areaId);
    for (var i = 0; i < ids.length; i++) {
        op.deleteObject(doc.queryEntityDirect(ids[i]));
    }
    return ids.length;
};
```

```js
/** The smallest area worth filling, in square drawing units. A slip of
 *  the hand is a click, not a room. */
AreaFillRun.MIN_AREA = 1.0;

/**
 * Turns a finished stroke into a boundary and its fill.
 *
 * ONE transaction: an area is a boundary plus a fill, and half of one
 * is not a thing a caver ever wants to undo into.
 *
 * \return {ok, id, layer, boundaryLayer, count, tripId, reason}
 */
AreaFillRun.commit = function(doc, di, points, key, opts) {
    var entry = CsArea.entryFor(key);
    if (isNull(entry)) {
        return { ok: false, reason: "no pattern called " + key, count: 0 };
    }
    if (points.length < 4) {
        return { ok: false, reason: "that stroke is too short to enclose " +
            "anything", count: 0 };
    }
    var verts = CsTrace.reduce(CsTrace.resample(points,
        CsTrace.spacingFor(CsUnits.nameOf(doc))), 0.05);
    if (CsArea.polygonArea(verts) < AreaFillRun.MIN_AREA) {
        return { ok: false, reason: "that loop encloses almost nothing",
            count: 0 };
    }

    // Feature Trace and ScatterBreakdown use. There is no plan button
    // and no profile button.
    var region = CsTrace.profileRegion(doc);
    var bays = CsTrace.sectionBays(doc);
    var frame = CsProfileBox.frameAt(doc, region, verts[0], bays);
    var fillLayer = CsLayers.twinFor(entry.layer, frame);
    var edgeLayer = CsLayers.twinFor(entry.boundaryLayer, frame);
    var run = CsProfileBox.runForPath(CsProfileBox.boxes(doc), verts);
    if (frame === "profile" && !isNull(run)) {
        fillLayer = CsLayerVariants.nameFor(fillLayer, run);
        edgeLayer = CsLayerVariants.nameFor(edgeLayer, run);
    }

    var locked = AreaFillRun.refusalReason(doc, [fillLayer, edgeLayer]);
    if (locked !== "") {
        return { ok: false, reason: locked, count: 0 };
    }

    var id = CsUuid.create();
    var seed = CsArea.newSeed();
    var op = new RAddObjectsOperation();
    CsLayers.ensure(doc, di, fillLayer);
    CsLayers.ensure(doc, di, edgeLayer);

    var spline = CsTrace.fitSpline(doc, verts);
    spline.setClosed(true);
    var boundary = new RSplineEntity(doc, new RSplineData(spline));
    boundary.setLayerId(doc.getLayerId(edgeLayer));
    CsTags.set(boundary, CsArea.ID_KEY, id);
    CsTags.set(boundary, CsArea.PATTERN_KEY, key);
    CsTags.set(boundary, CsArea.SCALE_KEY, String(opts.scale));
    CsTags.set(boundary, CsArea.DENSITY_KEY, String(opts.density));
    CsTags.set(boundary, CsArea.SEED_KEY, String(seed));
    var trip = CsTrace.tripFor(doc, frame, verts, bays);
    if (!isNull(trip)) {
        CsTags.set(boundary, "TripId", String(trip));
    }
    op.addObject(boundary, false);

        { id: id, seed: seed, scale: opts.scale, density: opts.density,
          layer: fillLayer });
    di.applyOperation(op);
    return { ok: built.ok, id: id, layer: fillLayer,
        boundaryLayer: edgeLayer, count: built.count, tripId: trip,

};
```

```js
/**
 * Where each section sits in a grid `columns` wide.
 *
 * A section ALONE on the last row spans the width rather than leaving a
 * hole beside it -- a dock is narrow and half of one is not worth
 * wasting (Nathan, 2026-09-11).

CsPanel.gridSpans = function(count, columns) {
    var cols = isNull(columns) || columns < 1 ? 1 : columns;
    var out = [];
    for (var i = 0; i < count; i++) {
        var row = Math.floor(i / cols);
        var col = i % cols;
        var lone = (col === 0) && (i === count - 1);
        out.push({ row: row, col: col, span: lone ? cols : 1 });
    }
    return out;
};
```

```js
        }
```
