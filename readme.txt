CaveCAD

This is CaveCAD, based on QCAD version 3.33.

CaveCAD is an application for computer aided drafting (CAD) in two
dimensions (2D), tailored for drawing cave surveys and maps.

CaveCAD is a modified version of QCAD Community Edition by RibbonSoft GmbH
(https://qcad.org). It is not affiliated with or endorsed by RibbonSoft.

optional exceptions (see LICENSE.txt, gpl-3.0.txt and gpl-3.0-exceptions.txt
for details). Complete source code, including all modifications, is
available at:

    https://github.com/Nate-the-Ace/cavecad-src (branch: cavecad)

A summary of modifications from upstream QCAD is in NOTICE.md.
